# Fairuz Siam — Frontend

Online shop for Fairuz Siam handmade jewelry (English / Arabic). Built with Next.js 16 + TypeScript.

**Live preview:** https://youssefseyam212.github.io/fairuz-siam-frontend/

> This is a design preview. Products are sample data, the bag is saved only in your browser,
> and no real orders or payments happen.

## What to check

- Home, Shop (filters, sort), product pages, bag (drag it closed), checkout
- Arabic: the **عربي** button in the header switches language and direction
- Theme: the circle button cycles device / light / dark
- Mobile: open the link on a phone or narrow the browser window

## Run locally

```bash
npm install
npm run dev   # http://localhost:3000
```

Every push to `main` rebuilds and redeploys the preview automatically (GitHub Actions → Pages).
